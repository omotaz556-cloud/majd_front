# منصة ألعاب مجد - الفرونت إند

فرونت إند React (Vite + Tailwind) بيتصل مباشرة بالباك إند الموجود
(`majd-games-backend-phase2-updated`) بدون أي تعديل على الـ API.

## تشغيل سريع

```bash
# 1. شغّلي الباك إند الأول (بورت 5000 افتراضياً)
cd ../backend
npm install
npm run seed:games   # لو أول مرة - بيضيف الألعاب التلاتة
npm run dev

# 2. في تيرمينال تاني، شغّلي الفرونت إند
cd majd-frontend
npm install
cp .env.example .env   # عدّلي VITE_API_URL لو الباك إند على عنوان مختلف
npm run dev
```

هيفتح على `http://localhost:5173`.

## اللي اتبنى في المرحلة دي

- تسجيل دخول / إنشاء حساب (يتصل بـ `/api/auth`)
- صفحة الألعاب (تجيب من `/api/games`)
- 3 ألعاب فعلية قابلة للعب فعلياً، متوافقة مع الـ `rules` المحفوظة في كل لعبة بالباك إند
- تدفق كامل: بدء جولة → لعب → إرسال النتيجة → عرض هل اتقبلت ولا اترفضت
- لوحة متصدرين لكل لعبة، صفحة محفظة، شريط "Arcade Ticker" متحرك
- **شحن الرصيد الحقيقي (Moyasar)** - مودال دفع كامل بيستخدم `Moyasar.js` من المتصفح
  مباشرة (بيانات الكارت متعديش على سيرفرنا خالص)
- **زر الإعلان المكافئ (Rewarded Ad)** في صفحة المحفظة - التدفق والتحقق الحقيقي
  على السيرفر جاهزين، استدعاء شبكة الإعلانات نفسها لسه محاكاة موضّحة بالكومنتات
- **لوحة تحكم الأدمن كاملة** (`/admin`): نظرة عامة وأرباح، إدارة مستخدمين،
  إدارة ألعاب
- سكربت `npm run promote:admin -- user@example.com` في الباك إند لترقية أول أدمن

## ملاحظة مهمة عن طبيعة المشروع

المنصة دي اقتصاد عملة افتراضية (Coins) بالكامل، شبيهة بفكرة 8 Ball Pool أو
Clash Royale - **مفيش ولا هيتضاف** نظام سحب (Withdrawal) ولا تحويل الـ Coins
لفلوس حقيقية ولا KYC. الـ Coins بتتكسب (إعلانات / شراء / فوز) وبتتصرف
(دخول ألعاب وتحديات) جوا النظام بس.

## جديد: نظام مكافآت الفوز + التحديات (Challenges)

- **مكافأة فوز على مستوى اللعبة العادية**: كل لعبة ممكن يتظبطلها (من لوحة
  الأدمن أو الـ API مباشرة) `reward.threshold_score` و `reward.reward_amount`.
  لو اللاعب حقق سكور verified يعدي الـ threshold، بياخد الـ Coins دي تلقائياً
  جوا `submitScore` - من غير أي تدخل يدوي.
- **موديول التحديات (`/api/challenges`, `/api/admin/challenges`)**: تحدي
  زمني مرتبط بلعبة معينة، بتكلفة اشتراك مرة واحدة (Coins)، واللاعب بيلعب أي
  عدد جولات خلال نافذة الوقت وأعلى سكور بتاعه هو اللي بيتحسب. لما التحدي
  يخلص، الأدمن بيعمل "settle" فيتوزع الجوائز على أصحاب أفضل المراكز حسب
  `prize_distribution`. فيه كمان "cancel" بيرجع رسوم الاشتراك لو التحدي اتلغى.
  - `POST /api/admin/challenges` - إنشاء تحدي جديد
  - `GET /api/challenges` - قائمة التحديات المتاحة للاعب
  - `POST /api/challenges/:id/join` - الانضمام (بيخصم entry_cost)
  - `POST /api/games/:slug/start` مع body `{ challengeId }` - يبدأ جولة كجزء من التحدي
  - `GET /api/challenges/:id/leaderboard` - الترتيب اللحظي
  - `POST /api/admin/challenges/:id/settle` - تسوية وتوزيع الجوائز
  - `POST /api/admin/challenges/:id/cancel` - إلغاء واسترجاع الرسوم
  - جرّبي `npm run seed:challenge` في الباك إند لإنشاء تحدي تجريبي فورًا

## الفجوات اللي لسه محتاجة تتبني (Backend/Frontend)

1. **دمج فعلي مع شبكة إعلانات ويب حقيقية** بدل المحاكاة الحالية (الـ SSV
   والتحقق والربط بالمحفظة جاهزين، الناقص هو استدعاء AdMob SDK الفعلي).
2. **صفحة callback بعد الدفع** لحالات التحويل لصفحة خارجية (3D Secure) في Moyasar.
3. **واجهة فرونت إند للتحديات** - الباك إند جاهز بالكامل (join/leaderboard/start)،
   لسه محتاج صفحات React تعرضها للاعب (قائمة تحديات، صفحة تحدي، ترتيب).
4. **تبويب إدارة العملة الافتراضية** في لوحة الأدمن - تعديل رصيد لاعب يدويًا
   وتقرير على تدفق الـ Coins الكلي داخل النظام.
